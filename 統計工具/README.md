# 🈁 正字記號統計工作台 (Tally Mark Analytics)

專為快速計數、活動登記、品管檢驗、問卷調查與各項數據統計所打造的現代化網頁應用系統。

---

## ✨ 核心特色與功能亮點

1. **五筆正字向量繪製引擎**：
   - 遵從標準五筆順序（一、丨、一、丨、一）精準繪製向量 SVG。
   - 每累積 5 筆自動組裝成完整「正」字，餘筆即時以半透明或動畫補齊。
   - 點擊卡片任何正字區即可直覺畫上一筆，並具備 Web Audio API 清脆敲擊反饋音效。

2. **自訂日期與項目管理**：
   - 可自由切換日期（今天、昨天、自訂日曆選擇），各日期數據獨立儲存。
   - 支援隨時新增、修改、歸零重置與刪除統計項目。
   - 支援自訂標籤顏色、目標筆數（自動計算達成率進度條）與備註備忘錄。

3. **三種檢視視圖**：
   - **🔲 正字卡片檢視 (Cards View)**：最直覺的正字方塊與大型按鈕操作。
   - **📋 明細清單表格 (Table View)**：表格化呈現正字迷你轉換與快速批次操作。
   - **📊 數據分析儀表板 (Analytics View)**：包含圓餅佔比圖、項目筆數排行長條圖與 7 天歷史趨勢折線圖。

4. **完整資料保存與多格式匯出**：
   - 瀏覽器 `localStorage` 自動持久化儲存，重新整理或關閉視窗不遺失資料。
   - **匯出 CSV / Excel**：內建 UTF-8 BOM，在微軟 Excel 中直接開啟繁體中文不亂碼。
   - **匯出高解析度圖卡**：一鍵產生包含當日統計明細與正字進度的高質感 PNG 圖卡。
   - **列印友善 (Print Mode)**：已針對 A4 紙張與列印樣式進行排版優化。

5. **現代視覺設計**：
   - 支援深色模式 (Dark Theme) 與淺色模式 (Light Theme) 一鍵切換。
   - 支援手機、平板與桌上型電腦全響應式版面。

---

## 🚀 如何開始使用

1. **直接開啟**：
   - 在電腦檔案總管中雙擊 `index.html`，即可使用預設瀏覽器（Chrome, Edge, Safari, Firefox）直接開啟使用。
2. **本機伺服器（可選）**：
   - 亦可透過任何 HTTP Server 開啟（如 Python: `python3 -m http.server 8080`）。

---

## ⌨️ 快捷操作

- `點擊正字卡片`：直接畫上 1 筆 (+1)
- `+1 筆 按鈕`：累加 1 筆
- `+5 按鈕`：直接累加一個完整正字 (+5)
- `-1 筆 按鈕`：退回 1 筆 (-1)
- `# 數字圖示`：手動直接輸入任何精確總筆數
- `鍵盤 + 或 = 鍵`：快速為第一項劃上一筆
